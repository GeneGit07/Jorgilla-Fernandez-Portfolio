# Elaina Madrid — Virtual Assistant Portfolio

A standalone portfolio site built with Next.js App Router, TypeScript, and pnpm.

## Run locally

```bash
pnpm install
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Before publishing

The contact link uses `hello@example.com` as an explicitly marked placeholder. Replace it with Elaina's actual contact email. Service examples can also be tailored to her confirmed offerings.
