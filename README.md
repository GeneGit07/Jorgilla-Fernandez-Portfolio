# Elaina Julia Madrid Portfolio

A responsive, single-page portfolio built with Next.js, React, TypeScript, and plain CSS.

## Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Project structure

- `src/app/page.tsx` — portfolio sections and content
- `src/app/globals.css` — responsive styles and visual design
- `src/app/layout.tsx` — shared page layout and SEO metadata

The biography and project tracker are sample content. Replace the placeholder details and `hello@example.com` with Elaina’s real information before publishing.
